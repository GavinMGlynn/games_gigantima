# Completion plan

Phased road to done. Each item names **its verification** — an item without one
cannot be ticked. Tails discovered while implementing something go into this
file the moment they are found, not when someone remembers.

**`[x]` means 100% of the item, and nothing less.** Not "the parts the demo
exercises", not "enough to move on". An item whose module has any claimed
behaviour unimplemented stays `[ ]`, with the missing part named in its text —
see `CLAUDE.md`, *Never describe a partial module as working*. Splitting an
item to tick the easy half is the same violation wearing a different shape.

`[x]` done · `[ ]` not started, or **In progress** where the text says so

## Phase 1 — The world you can walk

- [x] One map class, single-scale, with terrain/prop/flags/region cells and a
      terrain property table. *Verification: the map tests in
      `tests/test_gigantima.c`.*
- [x] Deterministic generation from a seed. *Verification:
      `generation_is_reproducible_from_its_seed`,
      `the_generated_start_tile_is_always_walkable` over 60 seeds.*
- [x] Versioned map file, round-tripping byte for byte and rejecting garbage,
      truncation, wrong version and implausible dimensions without leaking.
      *Verification: `a_saved_map_reloads_byte_for_byte`,
      `loading_a_file_that_is_not_a_map_fails_cleanly`.*
- [x] Turn loop and world clock; a blocked move costs no turn.
      *Verification: the turn and clock tests.*
- [x] Depth-sorted renderer with a **pixel** camera. *Verification:
      `the_camera_moves_in_sub_tile_steps_while_walking`,
      `the_camera_clamps_to_the_map_edges`. Detail in `PROJECT_STATUS.md` — the
      tile-quantised camera passed every test and needed a screen recording to
      find.*
- [x] Keyboard and gamepad through one action stream, with repeat tied to the
      step animation. *Verification: `GG_REPEAT_RATE == GG_STEP_TICKS` in
      `gg_input.h`; the failure it prevents is described there.*
- [x] Art pipeline: four atlases, generated ids/rects, generated credits, all
      committed so a clone needs no art submodule. *Verification: the CI smoke
      test renders a frame with only `ext/sdl` and `ext/sdl_image` present.*
- [x] Debug window with map overview, clock and townsfolk roster.
      *Verification: `--debug` and F1; the roster shows each NPC's distance from
      its scheduled position.*
- [x] **Autotiled shorelines.** Three edge sets — grass bank, beach, and the
      shallow-to-deep drop-off — selected per cell from a neighbour mask, plus
      cellular smoothing of the generated water so the coast has no single-tile
      spurs for the missing concave pieces to expose.
      *Verification: `a_square_lake_selects_all_nine_edge_pieces`,
      `water_at_the_map_edge_draws_no_shoreline_against_nothing`,
      `deep_water_is_never_adjacent_to_land`,
      `the_coastline_has_no_isolated_puddles`; and a `--shot` frame of the lake.
      Detail in `PROJECT_STATUS.md`.*
- [ ] **Concave shoreline corners.** The LPC sheets carry no inner-corner
      pieces, so a coast that wraps around a promontory falls back to the
      interior fill and shows a square notch. Smoothing hides it on generated
      lakes; a hand-authored coastline will not be so lucky. Needs the four
      pieces drawn, or composited from the existing ring at bake time.
      *Verification: a map with a deliberate one-tile promontory renders with
      no square notch.*
- [ ] **Land-to-land transitions.** Grass still meets sand, dirt and desert
      with a hard edge; only water is autotiled. The same machinery applies,
      but it needs an edge set per terrain pair and a precedence order so two
      abutting transitions do not both claim the same cell.
      *Verification: a `--shot` frame of the desert boundary with no
      straight-line edge.*
- [ ] **Real buildings.** Walls, roofs, windows, doorframes and interior floors
      from the LPC Structure sheets, replacing the current rectangles of
      `GG_TILE_MOUNTAIN`. *Verification: a town frame in which buildings read
      as buildings; the terrain table no longer used for masonry.*
- [ ] **A* pathfinding with a per-turn budget**, replacing greedy stepping.
      *Verification: an NPC whose schedule point is behind a wall reaches it;
      a test that walks one across a town with an obstacle between.*
- [ ] **Light sources and indoor lighting.** `GG_CELL_INDOORS` is set and
      unused; the light quad covers the whole view. *Verification: a night
      frame in which a lit interior is brighter than the street.*

## Phase 2 — A game, not an engine

- [ ] **Save/load with named profiles.** Multiple players on one machine, each
      with their own saves; a save carries the world, the actors, the clock,
      inventory and progress, and resumes exactly. Versioned like the map
      format, and rejecting a foreign file the same way.
      *Verification: a round-trip test asserting a resumed game is
      byte-identical to the one saved, and that a profile's saves are not
      visible to another profile.*
- [ ] **Title screen, menus, setup and profile pages.** New game, continue,
      choose profile, options (scale, fullscreen, volume, rumble), quit.
      *Verification: every screen reachable and leavable by keyboard and by
      gamepad alone; a `--shot` frame per screen.*
- [ ] **Inventory that exists.** Pick up, drop, use, equip; weight or bulk.
      The current six counters are display only.
      *Verification: an item picked off the ground appears in the pack and is
      gone from the map, and survives a save/load.*
- [ ] **Keyword conversation.** Ultima's topic system: ask about a word, learn
      new words, some gated on flags. Dialogue in data, not C.
      *Verification: a conversation defined entirely in a data file, with a
      topic that only unlocks after another has been asked.*
- [ ] **Party and companions.** Recruit, follow, formation, and their own
      stats. *Verification: a companion follows through a door without
      blocking the player, over a long walk.*
- [ ] **Turn-based combat.** Initiative, melee and ranged, hit resolution,
      death and loot. *Verification: a scripted encounter with a fixed seed
      resolving identically every run.*
- [ ] **Magic.** Reagents, spellbook, a runic word system.
      *Verification: a spell defined in data, cast, with its effect and its
      reagent cost both observable.*
- [ ] **Bestiary in data.** Creature stats, behaviour and loot tables as
      files. *Verification: a creature added with no code change.*
- [ ] **Audio.** `ext/sdl_mixer` linked; music that follows the region and time
      of day, ambience, and effects driven from the simulation's event queue
      the way the rumble already is. Needs a CC0/OFL-equivalent sound set
      chosen and vendored with its attribution, as the art was.
      *Verification: a headless run with `SDL_AUDIODRIVER=disk` producing a
      capture with the expected events in it.*

## Phase 3 — Content at scale

The ambition is deep storylines and a large number of varied levels. None of
that is reachable while content is C, so the editor comes before the content.

- [ ] **Level editor** (`gigantima_editor`), a second frontend on the same
      core: paint terrain and props, place actors, edit schedules, define
      regions, set the start point, save and load `.ggmap`.
      *Verification: a map authored in the editor, saved, and played in the
      game with no code change.*
- [ ] **Actors, schedules and dialogue move out of C into map data.** Today
      the eight townsfolk are a table in `gg_game.c`.
      *Verification: `gg_game.c` contains no character names.*
- [ ] **Quest and story state machine**, with flags, stages and journal
      entries, all in data. *Verification: a two-stage quest completed, its
      journal updated, and the state surviving a save/load.*
- [ ] **World of many maps** with linked transitions, while keeping each map
      seamless internally. *Verification: walking between two authored maps
      preserves party, clock and inventory.*
- [ ] **The main storyline.** *Verification: playable start to finish.*

## Phase 4 — Fit and finish

- [ ] **Atlas regeneration checked in CI** — that the committed atlas is what
      the baker produces from the pinned art. Needs the art submodule in a
      scheduled job rather than every push. *Verification: a job that
      re-bakes and diffs.*
- [ ] **Deterministic replay**: record the action stream, play it back, assert
      an identical end state. The simulation is already integer-only and
      seeded, so this is cheap and makes every bug report reproducible.
      *Verification: a recorded session replays to an identical state hash.*
- [ ] **Packaging** per platform: an installable Windows build, a macOS
      bundle, and a Linux tarball, each with the assets alongside.
      *Verification: an artifact from CI that runs on a clean machine.*
- [ ] **Controller-only playability**, including text entry for profile names.
      *Verification: a full new-game-to-save loop with the keyboard unplugged.*
- [ ] **Accessibility**: rebindable keys, a larger HUD font option, and a
      colour-blind-safe palette for the debug overview.
      *Verification: each option exercised from the options page.*

## Tails found while building

Recorded here as they turn up, so they are not rediscovered:

- The `--shot` loop walked east until the turn counter advanced, and a blocked
  move costs no turn — so it spun forever the first time a seed put a wall to
  the east, which hung a sanitizer run for ten minutes. Fixed with a wait
  fallback and a bound. **Any loop of the form "act until the world advances"
  has this bug.**
- `SDLIMAGE_BUILD_SHARED_LIBS` defaults on and makes SDL_image look for
  `SDL3::SDL3-shared`, which a static SDL never creates; the failure reads
  "could not find a configuration file for package SDL3" and names neither.
  `BUILD_SHARED_LIBS` must be `OFF` before `add_subdirectory`.
- libpng pulls in zlib, and a system zlib whose CMake package advertises a
  `libz.a` it does not ship fails the configure. PNG now decodes through stb,
  which has no dependencies at all.
- A test that searched the generated world for a wall silently proved nothing
  on seeds that spawn in open ground. Build the situation explicitly.
