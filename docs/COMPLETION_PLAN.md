# Completion plan

The road to done, in phases. **This is the map, not the territory** — one line
per item, saying what it is and how you would know it works. How any of it is
actually built lives in `PROJECT_STATUS.md`, which is the file to read when you
want detail.

**`[x]` means 100% of the item, and nothing less.** Not "the parts the demo
exercises", not "enough to move on". An item with any claimed behaviour
unimplemented stays `[ ]`, with the missing part named in its text — see
`CLAUDE.md`, *Never describe a partial module as working*. Splitting an item to
tick the easy half is the same violation wearing a different shape.

Every item names its verification. An item without one cannot be ticked. Tails
found while implementing something go in at the bottom the moment they are
found, not when someone remembers.

`[x]` done · `[ ]` not started, or **In progress** where the text says so

## Phase 0 — Foundations

- [x] **C23 + CMake/Ninja build**, presets per platform with matching test
      presets. *Verification: every preset configures, builds and tests.*
- [x] **64-bit-only and C23 gates**, with `nullptr` probed rather than inferred
      from a version number. *Verification: the configure line names the
      resolved platform, compiler and standard.*
- [x] **Warnings as errors in every build type**, first-party targets only.
      *Verification: both presets build clean from a wiped tree.*
- [x] **`src/core/` layer boundary enforced at configure time** rather than by
      review. *Verification: a deliberate violation fails the configure with a
      named message.*
- [x] **CI on all four platforms** — Ubuntu, Rocky, Windows MSVC, macOS arm64 —
      plus a sanitizer job. *Verification: matrix green.*
- [x] **GPL-3.0, with the art and font carve-outs stated.** *Verification:
      `LICENSE`, `assets/LICENSES.md`, and `assets/CREDITS.md` generated by the
      baker rather than transcribed.*
- [x] **`ext/` submodules pinned**, only two of them needed to build.
      *Verification: CI initialises those two alone and renders a frame.*

## Phase 1 — The world you can walk

- [x] **One map class**, single-scale, with a terrain property table.
      *Verification: the map tests.*
- [x] **Deterministic generation from a seed.** *Verification: the same seed
      gives the same world, and the start tile is walkable over 60 seeds.*
- [x] **Versioned map file**, round-tripping byte for byte and refusing garbage,
      truncation and wrong versions without leaking. *Verification: the map file
      tests.*
- [x] **Turn loop and world clock**; a blocked move costs no turn.
      *Verification: the turn and clock tests.*
- [x] **Depth-sorted renderer with a pixel camera.** *Verification: the camera
      tests — though the tile-quantised camera passed every test it had and
      needed a screen recording to catch.*
- [x] **Keyboard and gamepad through one action stream**, with repeat tied to
      the step animation. *Verification: the repeat-rate constant, and the
      failure it prevents, are both spelled out in `gg_input.h`.*
- [x] **Art pipeline**: atlases, ids and credits all generated and committed, so
      a clone builds with no art submodule. *Verification: CI renders a frame
      with only SDL and SDL_image checked out.*
- [x] **Debug window** with map overview, clock and townsfolk roster.
      *Verification: `--debug`, or F1.*
- [x] **Autotiled shorelines** — grass bank, beach and drop-off, picked per cell,
      over water smoothed so the coast has no single-tile spurs. *Verification:
      the shoreline tests, and a `--shot` frame of the lake.*
- [x] **Concave shoreline corners**, composed at bake time out of the ring that
      was already there. *Verification: the concave-corner tests, and an authored
      scene of promontories, notches and islands.*
- [x] **Land-to-land transitions.** Grass bleeds a verge onto every other land
      terrain, as a set of pieces rather than one, so a one-tile road gets a
      verge on both sides. *Verification: the overlay tests.*
- [x] **Transitions between two non-grass terrains**, synthesised from the one
      overlay ring the sheet actually carries, and drawn once from the softer
      side. *Verification: the boundary tests, and an authored scene banding six
      terrains with no straight-line edge in it.*
- [x] **Real buildings, inside and out.** Walls block, the room does not, the
      roof lifts while you are inside it, and the rooms are furnished.
      *Verification: the building tests over 20 generated towns, and `--shot`
      frames of the street, the doorway and the room.*
- [x] **A\* pathfinding with a per-turn budget.** Deterministic, no
      corner-cutting, and an unreachable target still yields a step toward the
      closest cell reached. *Verification: the pathfinding tests, including a
      serpentine maze and a resident walking round a building.*
- [x] **Light that comes from objects, not from rules.** A prop carries a
      radius; a cell takes the brightest of sky, carried light and every emitter
      in reach, and an emitter does not reach through a wall. *Verification: the
      lighting tests, and `--shot` frames at noon, dusk and midnight.*

## Phase 2 — A game, not an engine

- [x] **Save/load with named profiles.** Everything is carried, including the
      RNG, so a resumed world goes on making the same decisions. Resuming is the
      default. *Verification: the save tests, plus a CI smoke test that plays,
      quits and resumes through the real binary.*
- [x] **Title screen, menus, setup and profile pages.** New game, continue,
      choose profile, options, pause, quit — six screens in all. Options covers
      window scale, fullscreen and rumble; **the music and effects rows are
      shown but inert**, and say "no sound yet" rather than pretending — a
      volume that adjusts nothing is not a control, so it belongs to the audio
      item below and is tracked there.
      *Verification: every screen reachable and leavable by keyboard and by
      gamepad alone, including naming a new journey; and a `--shot` frame per
      screen, taken in CI.*
- [x] **Inventory that exists.** Pick up, drop, use, equip, and a weight limit
      that bites. Items are things in the world with their own art, scattered
      through houses and under trees; the kinds are generated from the art
      alongside the props, so adding one is not a code change. **The only thing
      that can be held is a light** — a torch, which lights what you can see —
      because a sword that modified nothing would be a control that does
      nothing; weapons and armour land with combat.
      *Verification: an item picked off the ground appears in the pack and is
      gone from the map, and survives a save/load; and the pack tests, which
      were each checked by breaking the rule they pin and watching them fail.*
- [x] **Keyword conversation.** Ultima's topic system: everyone starts knowing
      two words, a topic can be asked when you know one of its words, and
      answers hand over words you did not have. That one rule is the whole of
      the gating — including across speakers, so a rumour heard from the
      merchant is what makes the gatekeeper worth asking. Every word of it is in
      `assets/dialogue.txt`; nothing is compiled in.
      *Verification: a conversation defined entirely in a data file, with a
      topic that only unlocks after another has been asked; a word learned from
      one person opening another's topic; and a `--shot` frame of the panel
      before and after a word is learned.*
- [x] **Party and companions.** Up to four walk with the Avatar. Recruiting is
      a topic in the dialogue file, not code, and the same word sends them home
      again. They follow in single file by walking where the Avatar walked, and
      one standing in the way steps aside rather than being talked at. Stats now
      live on the actor, so a companion has the health and level the Avatar has.
      *Verification: a companion follows through a door without blocking the
      player, over a long walk — the test walks in, out and back four times and
      fails if the Avatar is ever blocked or shares a tile.*
- [ ] **Turn-based combat.** Initiative, melee and ranged, hit resolution, death
      and loot. *Verification: a scripted encounter with a fixed seed resolving
      identically every run.*
- [ ] **Magic.** Reagents, spellbook, a runic word system.
      *Verification: a spell defined in data, cast, with its effect and its
      reagent cost both observable.*
- [ ] **Bestiary in data.** Creature stats, behaviour and loot tables as files.
      *Verification: a creature added with no code change.*
- [ ] **Audio.** Music that follows the region and the time of day, ambience,
      and effects driven from the simulation the way rumble already is. Needs a
      freely-licensed sound set vendored with its attribution, as the art was.
      Includes making the options page's music and effects rows live, which is
      where the volume control this project promised actually lands.
      *Verification: a headless run producing a capture with the expected events
      in it, and both volume rows changing what it contains.*

## Phase 3 — Content at scale

The ambition is deep storylines and a large number of varied levels. None of
that is reachable while content is C, so the editor comes before the content.

- [ ] **Level editor** (`gigantima_editor`), a second frontend on the same core:
      paint terrain and props, place actors, edit schedules, define regions, set
      the start point, save and load `.ggmap`.
      *Verification: a map authored in the editor, saved, and played in the game
      with no code change.*
- [ ] **Actors, schedules and dialogue move out of C into map data.** Today the
      eight townsfolk are a table in `gg_game.c`.
      *Verification: `gg_game.c` contains no character names.*
- [ ] **Quest and story state machine**, with flags, stages and journal entries,
      all in data. *Verification: a two-stage quest completed, its journal
      updated, and the state surviving a save/load.*
- [ ] **World of many maps** with linked transitions, while keeping each map
      seamless internally. *Verification: walking between two authored maps
      preserves party, clock and inventory.*
- [ ] **The main storyline.** *Verification: playable start to finish.*

## Phase 4 — Fit and finish

- [ ] **Atlas regeneration checked in CI** — that the committed atlas is what
      the baker produces from the pinned art. Needs the art submodule in a
      scheduled job rather than on every push. *Verification: a job that re-bakes
      and diffs.*
- [ ] **Deterministic replay**: record the action stream, play it back, assert an
      identical end state. The simulation is already integer-only and seeded, so
      this is cheap and makes every bug report reproducible.
      *Verification: a recorded session replays to an identical state hash.*
- [ ] **Packaging** per platform: an installable Windows build, a macOS bundle,
      and a Linux tarball, each with the assets alongside.
      *Verification: an artifact from CI that runs on a clean machine.*
- [ ] **Controller-only playability.** The menus and the naming alphabet are
      already pad-only. What is left is everything the world gains from here —
      each new verb, panel and prompt reachable with a pad as it lands — and
      walking the whole loop on real hardware rather than only in tests.
      *Verification: a full new-game-to-save loop with the keyboard unplugged.*
- [ ] **Accessibility**: rebindable keys, a larger HUD font option, and a
      colour-blind-safe palette for the debug overview.
      *Verification: each option exercised from the options page.*

## Tails found while building

Recorded here as they turn up, so they are not rediscovered:

- The `--shot` loop walked east until the turn counter advanced, and a blocked
  move costs no turn — so it spun forever the first time a seed put a wall to
  the east, which hung a sanitizer run for ten minutes. Fixed with a wait
  fallback and a bound. **Any loop of the form "act until the world advances"
  has this bug.**
- `SDLIMAGE_BUILD_SHARED_LIBS` defaults on and makes SDL_image look for
  `SDL3::SDL3-shared`, which a static SDL never creates; the failure reads
  "could not find a configuration file for package SDL3" and names neither.
  `BUILD_SHARED_LIBS` must be `OFF` before `add_subdirectory`.
- libpng pulls in zlib, and a system zlib whose CMake package advertises a
  `libz.a` it does not ship fails the configure. PNG now decodes through stb,
  which has no dependencies at all.
- A test that searched the generated world for a wall silently proved nothing on
  seeds that spawn in open ground. Build the situation explicitly.
- Options was reachable from the title *and* from the pause menu, and backed out
  to the title from both — dropping a player out of a game with unsaved turns
  behind them. **A screen with two ways in needs to remember which one it was.**
- The warning sets have to agree across compilers. GCC and Clang were passed
  `-Wno-unused-parameter` while MSVC's `/W4 /WX` makes the same thing fatal, so
  a dead parameter built clean on every developer machine and failed only in CI,
  on the one platform nobody builds locally. **A warning enabled on one compiler
  and suppressed on another is a remote lint nobody can run.**
- "Not entirely transparent" is not a measurement. The wall torch passed the
  baker's art check with nine texels — the tip of a flame, the rest of the torch
  being on the row below — and baked to an invisible sprite. **A check on art
  has to be a coverage figure, not a yes/no.**
