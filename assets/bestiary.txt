# What lives in the vale.
#
# A creature is a row. Adding one is an edit to this file and nothing else -
# no code knows the name of anything in here.
#
#   creature ID          the name a data file calls it by
#     name TEXT          what the message log calls it
#     art ID             which composited sprite to wear
#     health N           what it can take
#     level N            counts toward landing a blow
#     speed N            energy a turn; 100 is one action, 200 is two
#     damage N           what it deals
#     guard N            what it turns aside
#     reach N            1 is arm's length; more means it throws
#     notice N           how near you must come before it cares
#     flees N            health below which it would rather be elsewhere
#     loot ID MIN MAX PC  a line of its loot table, PC per cent of the time
#     worth N            what killing it teaches the party; defaults to its health
#     haunts N           how many of it a world holds, put down where there is room
#     haunts N MAP       how many that map holds, the first time it is walked into
#     haunts N MAP X Y   and standing on that tile - which is how a story places
#                        its villain without a line of C knowing where he is
#
# This art set has no monsters in it at all - it is people, head to foot - so
# the vale's trouble is people. A caravan that never arrived is better served
# by that than by a wolf.
#
# **The road arms you, and it teaches you.** The Avatar leaves the vale with no
# weapon and at level one; what is carried up the north road is taken off the
# brigands on it, and what is learned is what they and the story are worth. The
# man at the end is beatable by somebody who fought their way there and not by
# somebody who ran past. That balance is these numbers and nothing else - see
# a_party_that_walked_the_road_can_beat_the_man_at_the_end_of_it, which measures
# it both ways round on every test run.
