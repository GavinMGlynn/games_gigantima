# What lives in the vale.
#
# A creature is a row. Adding one is an edit to this file and nothing else -
# no code knows the name of anything in here.
#
#   creature ID          the name a data file calls it by
#     name TEXT          what the message log calls it
#     art ID             which composited sprite to wear
#     health N           what it can take
#     level N            counts toward landing a blow
#     speed N            energy a turn; 100 is one action, 200 is two
#     damage N           what it deals
#     guard N            what it turns aside
#     reach N            1 is arm's length; more means it throws
#     notice N           how near you must come before it cares
#     flees N            health below which it would rather be elsewhere
#     loot ID MIN MAX PC  a line of its loot table, PC per cent of the time
#     haunts N           how many the generator puts in a map
#
# This art set has no monsters in it at all - it is people, head to foot - so
# the vale's trouble is people. A caravan that never arrived is better served
# by that than by a wolf.
